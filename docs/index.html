Poker Docs

Docs

Poker is a personal study book on poker and poker strategy, a sibling of Return Of. Each chapter asks what the great players would say. This page explains how the site is put together.

How the site is laid out

Plain HTML, CSS, and a little JavaScript. There is nothing to install: open index.html in a browser and it works.

  • index.html: the welcome page. For now, a style sampler.
  • docs/index.html: this page.
  • css/themes.css: one block of values per style.
  • css/site.css: layout and components. It reads theme values and never hard-codes a color or font.
  • js/version.js: the version number, in one place.
  • js/switch.js: the sampler's style switch.
  • tools/check.js: the checks that gate every deploy.
  • reference/: source material, including the starting hands guide and the Oval Table council.

How styles work

A style applies to whatever element carries a data-style attribute, and styles nest. To add a style, copy a block in css/themes.css, rename it, and change the values. Values come from the Visual Design Laboratory.

  • academia: Dark Academia. Parchment, ink, oxblood, and classical serifs.
  • deco: Art Deco. Black and gold, with tall geometric capitals.
  • blend: the book's own mix. Academia's paper, ink, and serif body, with Deco's display capitals and gold rules. Gold fails contrast on cream, so here it marks rules and ornaments, never text.

The welcome page opens in the blend, and the switch shows all three. The choice is remembered in the browser when it allows that.

Council voices

The book draws on a council of players: the Oval Table to start, others as chapters need them. Their voices come in two kinds, and the two never look alike.

  • A real quote sits in quote marks, set between gold rules, with a link to its source. No source, no quote.
  • An imagined voice ("what Brunson might say") is paraphrase in a shaded box. It never uses quote marks, and it says it is our reading of that player's published ideas.

The deploy check enforces both, on every page: a real quote without a source link fails, and so does an imagined voice with quote marks (in any spelling) or without the words "our reading". A <blockquote> or <q> outside a real-quote block fails too, since it has no source.

Versioning and releases

The site follows SemVer and keeps a changelog. The version shows in the footer of the welcome page and at the top of this one, so a deploy can be checked by eye.

  1. Bump POKER_VERSION in js/version.js.
  2. Add a ## [x.y.z] entry to CHANGELOG.md.
  3. Run node tools/check.js.
  4. Commit, push to main, then tag: git tag vX.Y.Z && git push --tags.

How it ships

Every push to main runs the checks in GitHub Actions. If they pass, the same workflow publishes the site to GitHub Pages. A failing check never reaches the live site. A deploy is done when the live page shows the new version.

Backlog and issues

Work is tracked in GitHub Issues. Each issue carries one MoSCoW label, one effort label, and one type label. Loose ideas live in BACKLOG.md.

Decisions

  • November 20, 2026: built the same way as Return Of. Plain static files, styles scoped by data-style, a deploy check, and GitHub Pages through Actions. The tradeoff: the header and footer are copied between pages until a build script is worth adding.
  • November 20, 2026: the look is chosen from a live sampler. Dark Academia, Art Deco, and a blend are shown side by side on the real site, at real phone widths. Building one style blind would likely have meant building twice.
  • November 20, 2026: real quotes need a source; imagined voices are labeled. Return Of bans quotes from real people. This book is built around the council, so it allows them, with a source link, and keeps invented voices visibly apart.
