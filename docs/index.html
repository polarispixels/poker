The Long Game is a personal study book on live No-Limit Hold'em, a sibling of Return Of. Each chapter asks what the great players would say, and ends with a piece of table math. This page explains how the site is put together.

How the site is laid out

Plain HTML, CSS, and a little JavaScript. There is nothing to install: open index.html in a browser and it works. One small script builds the chapter pages, and its output is saved in the repo.

  • index.html: the title page and the contents.
  • content/chapters.json: the book's parts, chapters, and appendices, in order.
  • content/chapters/: one file of content per chapter. This is where the writing lives.
  • chapters/: the finished pages. Built by a script: do not edit them by hand.
  • js/figures.js: the figure kit, plus range and odds arithmetic.
  • css/themes.css: one block of values per style. css/site.css: layout and components, reading theme values only.
  • tools/build.js, tools/check.js, tools/publish.js, tools/poker.js: build, deploy gate, one-chapter release, and the poker calculator.
  • docs/: this page, the figure gallery, and the writing guide (docs/writing-guide.md).
  • reference/: source material: the starting hands guide, the Oval Table council, and the book outline.

The look

The book uses the blend style, chosen from a live sampler on November 20, 2026: Dark Academia's parchment, ink, and serif text, with Art Deco's display capitals and gold rules. Values come from the Visual Design Laboratory. Gold fails contrast on cream, so it marks rules and ornaments, never text. The academia and deco blocks stay in css/themes.css, and any element can take one with a data-style attribute.

How chapters work

A chapter is one content file, such as content/chapters/05-odds-and-outs.html, holding only headings, paragraphs, and figures. node tools/build.js wraps each one in the shared page and rewrites the contents list. A chapter with no content file shows as "To come".

Three shorthands keep content files short. The build expands them:

  • [[As Kh]] draws playing cards. Suits are s, h, d, c; x is any suit; ?? is a face-down card.
  • {{ch:7}} links to Chapter 7 by title. A letter links to an appendix.
  • A figure numbered Fig. or Table is numbered for you (Fig. 7.1, Table 7.2).

Every chapter opens with a lead paragraph, gives every section a figure, carries at least one council voice, and closes with one Table Math box. The deploy check enforces all four. The full rules are in the writing guide.

Figures

Figures are first-class parts of the book. The gallery shows every type with its source. A kit figure is a type and a JSON spec:

<div data-fig="bars"><script type="application/json">{ ... }</script></div>
  • Kit types, drawn by js/figures.js: bars, columns, line, split, dots (times out of 100), range (the 13 by 13 hand grid), table (seats, stacks, and bets), scatter, and heat.
  • Components in plain HTML: tables, hand logs, flows, trees, stats, compares, timelines, drills, and inline SVG.
  • Charts are drawn at the real width of their container, not scaled, so labels stay readable on a phone. They redraw when the window changes size.
  • Color has one meaning across the book. Ink is the main line or the hero. Oxblood (accent) is risk, loss, a bluff, or the villain. Teal (accent2) is value or the alternative. Gold is a highlight. A good outcome is never oxblood.
  • Every figure says where its numbers come from, and every kit figure carries a sentence describing it for readers who cannot see it.

Where the numbers come from

No poker number in the book is quoted from memory. tools/poker.js counts every possible board for an equity, and the range and odds arithmetic lives in js/figures.js. Both are tested by the deploy check.

node tools/poker.js equity "AsKs" "QhQd"
node tools/poker.js vsrange "AsKs" "TT+,AQs+,AKo" --board "Ts 9s 2d"
node tools/poker.js draw 9
node tools/poker.js combos "22+,ATs+,KQo"
node tools/poker.js odds 100 50

Example hands are invented for teaching and say so. They are not real hand histories.

Council voices

The book draws on a council of players: the Oval Table to start, others as chapters need them. Their voices come in two kinds, and the two never look alike.

  • A real quote sits in quote marks, set between gold rules, with a link to its source. No source, no quote.
  • An imagined voice ("what Brunson might say") is paraphrase in a shaded box. It never uses quote marks, and it says it is our reading of that player's published ideas.

The deploy check enforces both, on every page: a real quote without a source link fails, and so does an imagined voice with quote marks (in any spelling) or without the words "our reading". A <blockquote> or <q> outside a real-quote block fails too, since it has no source.

Versioning and releases

The site follows SemVer and keeps a changelog. The version shows in every footer, so a deploy can be checked by eye. The book is published one chapter at a time: each new chapter is a minor version.

  • A chapter: write the draft in drafts/ (not committed), check it with node tools/check.js --draft drafts/NN-slug.html, then run node tools/publish.js N "summary". That one command moves the draft in, bumps the version, adds the changelog entry, builds, checks, commits, pushes, and tags. If the check fails, it puts everything back.
  • Anything else: bump POKER_VERSION in js/version.js, add a ## [x.y.z] entry to CHANGELOG.md, run the build and the check, commit, push main, and tag.

How it ships

Every push to main runs the checks in GitHub Actions. If they pass, the same workflow publishes the site to GitHub Pages. A failing check never reaches the live site. A deploy is done when the live page shows the new version.

Backlog and issues

Work is tracked in GitHub Issues. Each issue carries one MoSCoW label, one effort label, and one type label. Loose ideas live in BACKLOG.md.

Decisions

  • November 20, 2026: built the same way as Return Of. Plain static files, styles scoped by data-style, a deploy check, and GitHub Pages through Actions.
  • November 20, 2026: the look is the blend, chosen by Ryan from a live sampler of Dark Academia, Art Deco, and a mix of the two.
  • November 20, 2026: real quotes need a source; imagined voices are labeled. Return Of bans quotes from real people. This book is built around the council, so it allows them, with a source link, and keeps invented voices visibly apart.
  • November 20, 2026: the title is The Long Game. Ryan chose it over the outline's working title, The Complete Game. The outline's subtitle stays.
  • November 20, 2026: figures are declared, not programmed. Return Of has one draw function per chart. Here a chapter gives a figure type and a JSON spec, and a small kit draws it. The tradeoff: a figure the kit cannot draw needs a new type or hand-written SVG, but a writer can add a correct, themed figure without touching code, and the check can validate every spec.
  • November 20, 2026: numbers come from a calculator in the repo. Poker odds are easy to misremember. tools/poker.js counts exact equities, so writers and reviewers compute every figure. The tradeoff: range-against-range numbers before the flop are sampled, not exact, and say so.
  • November 20, 2026: the book is published one chapter at a time. Ryan wants to read along while it is written. Each chapter is drafted, reviewed for accuracy, and released as its own version by one locked command, so several can be in progress at once. Unwritten chapters show as "To come". All chapters ship as preliminary drafts.
  • November 20, 2026: the default game is live $2/$5, nine-handed, 100 big blinds. One setting across the book keeps examples comparable. Online play is out of scope for now, by the outline's second draft.
