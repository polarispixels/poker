# Poker

A personal study book on poker and poker strategy, built as a series of web pages. Each chapter asks what the great players would say.

- **Live:** https://polarispixels.github.io/poker/
- **Docs:** https://polarispixels.github.io/poker/docs/
- **Changes:** [CHANGELOG.md](CHANGELOG.md)
- **Work:** [Issues](https://github.com/polarispixels/poker/issues) and [BACKLOG.md](BACKLOG.md)

## Run it

There is nothing to install. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Check it

```bash
node tools/check.js
```

The same check gates every deploy. Pushing to `main` publishes the site if it passes.
